## Why

The AI programming community needs search so visitors can discover public technical articles and users beyond the homepage recommendation feed.

## What Changes

- Add public article search by title, summary, body, and tags.
- Add public user search by nickname and bio.
- Add grouped search results separating articles and users.

## Impact

- Affected capability: `search`
- Supports content discovery, author discovery, and CSDN-style technical lookup behavior.
