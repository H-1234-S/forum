## Why

The AI programming community needs tags and lightweight recommendation flows so v1 can organize technical articles without categories while preserving the signals needed for future Douyin-style personalization.

## What Changes

- Add tag-only article organization requirements.
- Add user tag selection and new-tag proposal behavior.
- Add administrator tag normalization requirements.
- Add homepage recommendation feed requirements.
- Add guest and logged-in personalization rules.
- Add hot ranking and related article recommendation requirements.

## Impact

- Affected capability: `tags-and-recommendations`
- Supports article discovery, search relevance, related articles, homepage feed ranking, and future personalization.
