## Why

The AI programming community needs notifications so users can notice social interactions and governance events without manually checking every article, comment, or profile page.

## What Changes

- Add notification creation for comments, replies, likes, follows, and article moderation changes.
- Add unread/read notification state.
- Add authenticated personal notification page requirements.

## Impact

- Affected capability: `notifications`
- Supports user engagement, moderation transparency, and personal center workflows.
