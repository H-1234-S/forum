## Why

The AI programming community needs a shared platform and UI foundation so all v1 capabilities can run on a consistent Next.js full-stack architecture with typed APIs, database persistence, local development support, responsive layouts, dark mode, image storage, and infinite scrolling.

## What Changes

- Add Next.js App Router and TypeScript architecture requirements.
- Add tRPC and TanStack Query data-flow requirements.
- Add Prisma and PostgreSQL persistence requirements.
- Add Docker PostgreSQL local development requirements.
- Add local filesystem image storage requirements.
- Add responsive UI and dark mode requirements using shadcn/ui and Tailwind CSS.
- Add infinite scrolling support for homepage recommendations.

## Impact

- Affected capability: `platform-and-ui`
- Provides the shared foundation used by accounts, articles, recommendations, comments, notifications, search, reports, admin, and AI assistance.
